# Genetic Inheritance Simulation

This project models how **human blood types** are passed from parents to offspring, demonstrating the biological principles of **genetic inheritance** through a simplified simulation.

## 🧠 Biological Concepts
- **Alleles and Blood Type Genes (A, B, O)**
- **Mendelian Inheritance**
- **Random genetic variation across generations**
- **Family tree representation of genetic lineage**

## ⚙️ Overview
Each person inherits **two alleles** (one from each parent).  
Across generations, these combinations determine an individual's **blood type**.  
The simulation creates a multi-generational family tree showing how genes flow through ancestry.

## 🧪 Scientific Insight
This simulation helps visualize how **genetic variation** and **inheritance probability** shape observable traits (phenotypes) such as blood type.
