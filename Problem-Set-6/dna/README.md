# DNA Profiling and Identification

This project performs **forensic DNA analysis** by comparing genetic markers to identify individuals, inspired by real-world techniques used in **genetics and forensic biology**.

## 🧠 Biological Concepts
- **Short Tandem Repeats (STRs)** — repeating sequences in DNA  
- **Genetic fingerprinting** used for identification  
- **Variation in STR length among individuals**

## ⚙️ Overview
1. Reads a database of known DNA profiles containing STR counts for each person.  
2. Analyzes a new DNA sequence to measure the **number of consecutive STR repeats**.  
3. Matches the DNA pattern to the individual with identical STR counts.


## 🧪 Scientific Insight
STR-based profiling is widely used in **genetic research**, **paternity testing**, and **forensic investigation**.  
This project demonstrates the biological logic behind how a small piece of DNA can uniquely identify a person.

## 📂 Files
- `dna.py` — DNA profiling script  
- `databases/` — STR databases for known individuals  
- `sequences/` — DNA sequence samples for testing
